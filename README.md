# Portfólio de João Marcos

Site estático em `index.html`, `style.css` e `script.js`, sem framework e sem build. Publicado pelo GitHub Pages em https://jmarcosvm.github.io.

## Estrutura

```
index.html   style.css   script.js
assets/      foto, imagem de compartilhamento e ícone
docs/        currículos em PDF (CV_AI_Builder, CV_IA_Operacoes e CV_Engenharia_de_Dados)
```

## Rodar localmente

Abra `index.html` no navegador ou sirva a pasta com qualquer servidor estático.

## Regras de conteúdo

- O site nunca afirma algo mais forte do que o README do repositório de cada projeto. O que está planejado aparece como planejado.
- Casos da Juntos sem nomes de pessoas, empresas parceiras ou valores internos. Tempos são estimativas pessoais.
- Dados em qualquer gráfico ou imagem devem ser fictícios e rotulados.
